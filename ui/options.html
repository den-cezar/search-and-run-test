Repositories

Each repo: owner, repo, workflow file, the path base to strip when building the pytest node ID, and the list of workflow_dispatch inputs its workflow accepts.

How to set up a repository
  • Name — any label shown in the popup (e.g. my-tests).
  • Owner / Repo — the GitHub owner/repo (e.g. your-org/your-test-repo).
  • Workflow file — the .yml file under .github/workflows/ that accepts the dispatch inputs.
  • Branch — git ref the workflow is dispatched on (e.g. main).
  • Path base to strip — folder prefix removed from a search hit to build the node ID (relative/path.py::test_name).
  • Workflow inputs — add one row per input your workflow's workflow_dispatch declares. For each: the Input key (exact input name), a Label, a Type (select, text, number, checkbox), Options for select (comma-separated, must match the workflow's allowed choices or dispatch fails with 422), and a Default.
  • Test path — mark exactly one input as the test-path target; it is auto-filled with the selected test's node ID (relative/path.py::test_name) and shown read-only in the popup.
